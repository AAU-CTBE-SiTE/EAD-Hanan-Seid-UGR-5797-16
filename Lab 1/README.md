# Lab 1: Java Maven Starter Project

A Java application demonstrating database connectivity using JDBC, MySQL, and Apache Maven.

## Technologies Used

- Java
- Apache Maven
- JDBC
- MySQL

## Prerequisites

Before running the application, ensure the following are installed:

- Java Development Kit (JDK)
- Apache Maven
- MySQL Server
- Git

## Database Configuration

The application connects to the `java_project` database on the local MySQL server.

Configure your MySQL credentials in `JDBCdemo.java` before running the application.

## Running the Application

1. Open the project in IntelliJ IDEA.
2. Ensure MySQL Server is running.
3. Create the `java_project` database.
4. Run the `JDBCdemo` class.

## Expected Output

    Connected successfully!
